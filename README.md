# Flower Gift Shop

Flower Gift Shop is a Java Swing desktop application developed as an Enterprise Application Development coursework project.

## Features

- User Login
- Dashboard
- Customer Management
- Product Management
- Category Management
- Supplier Management
- Sales Management
- Stock Quantity Update
- Input Validation
- Custom Exception Handling
- JasperReports Sales Report
- MySQL Database Integration
- Git Version Control

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- JasperReports
- Apache NetBeans
- Git & GitHub
- Launch4j

## Database Setup

1. Install XAMPP.
2. Start Apache and MySQL.
3. Open phpMyAdmin.
4. Create/import the database using:

`database/flower_gift_shop.sql`

5. The application uses:

- Database: `flower_gift_shop`
- Host: `localhost`
- Port: `3306`
- Username: `root`
- Password: empty

## Default Login

Username: `admin`

Password: `1234`

## Running the Application

### Using JAR

Open the `dist` folder and run:

`FlowerGiftShop.jar`

### Using EXE

Open the `dist` folder and run:

`FlowerGiftShop.exe`

## Project Structure

- `src/` - Java source files
- `database/` - MySQL database script
- `dist/` - JAR and EXE files
- `lib/` - Required libraries

## Reports

The application includes a JasperReports Sales Report using data from multiple database tables.
